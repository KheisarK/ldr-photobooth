# Frontend

This directory is reserved for the React + Vite client.

The frontend owner is responsible for:

- booth creation and join screens;
- camera permission, countdown, and four-photo capture flow;
- loading, error, waiting, and completed states;
- combined photostrip presentation; and
- browser download of the final image.

For the first hour, the UI may use mock responses that match `../docs/API.md`. Do not add routing, state-management, or UI libraries unless the MVP actually needs them.

When implementation begins, scaffold Vite directly into this directory and preserve `.env.example`.
